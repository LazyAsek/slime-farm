# 🟢 Slime Farm

**My first serious programming project.**

Slime Farm is a small incremental / idle game written in Java. The idea is simple: hatch slime eggs, collect different types of slimes, build your farm and gradually increase your passive income.

This project was one of my first major steps into programming. I built it to learn Java, experiment with game development and understand how different systems work together in a complete application.

## 🎮 Gameplay

- 🥚 **Hatch eggs** – Collect eggs and hatch new slimes.
- 🟢 **Collect slimes** – Discover and unlock different slime tiers.
- 💰 **Earn coins** – Your slimes generate passive income over time.
- 🛒 **Buy new slimes** – Expand your farm and increase your earnings.
- ⚡ **Upgrade your farm** – Purchase upgrades to improve your progress.
- 🖱️ **Move slimes** – Drag slimes around your farm and arrange them as you like.
- 💾 **Save your progress** – Your coins, slimes, unlocks and upgrades are saved automatically.

## 🛠️ Built With

- **Java** – Main programming language.
- **Java Swing** – Game window and rendering.
- **Java AWT** – Graphics, mouse input and collision detection.
- **ImageIO** – Loading game textures and sprites.
- **Custom assets** – Game graphics, UI elements and animations.
- **WAV audio** – Background music and sound effects.

## 🚀 Getting Started

### Requirements

- Java Runtime Environment (JRE).
- Java Development Kit (JDK) if you want to work with the source code.

### Running the Game

1. Clone this repository:

   ```bash
   git clone https://github.com/LazyAsek/slime-farm.git
   ```

2. Navigate to the repository directory:

   ```bash
   cd slime-farm
   ```

3. Run the compiled game:

   ```bash
   java -jar slime-farm.jar
   ```

**Note:** The game uses resource paths relative to the project directory, so keep the `Slime-Farm` folder alongside the JAR file.
